# Descripcion
Para el registro y correccion de errores, se deben seguir las siguientes instrucciones:

1. Formato
Todos los errores deben de quedar registrados en un archivo llamado "error".md, donde "error" es el titulo del error.
El contenido de este archivo debe puede aumentar o quitar cosas, pero debe de tomar en cuenta la siguiente base:
- Titulo del error
- Area del error (frontend, backend, database)
- Diagnostico
- Plan implementado de solucion

2. Ruta
Todos los archivos generados deben de encontrarse dentro de la misma carpeta donde se encuentra este archivo, osea, en la carpeta:
"/Errores encontrados/"
